# 🥋 BJJ Fighter Website

Website ini dibuat sebagai tugas mata kuliah Pengembangan Desain Web.

## 📌 Deskripsi
Website ini bertema Brazilian Jiu-Jitsu (BJJ), yang menampilkan informasi dasar tentang BJJ serta teknik submission populer yaitu armbar.

## 🎯 Fitur Website
- Halaman utama dengan tampilan modern (dark theme)
- Penjelasan tentang BJJ
- Penjelasan teknik armbar
- Gambar ilustrasi BJJ
- Button interaktif dengan alert JavaScript

## 🛠️ Teknologi yang Digunakan
- HTML
- CSS
- JavaScript

## 📷 Konten
Website ini menggunakan gambar latihan BJJ dan teknik armbar untuk mendukung tampilan visual.

## 🚀 Tujuan
Website ini dibuat untuk memenuhi requirement tugas, yaitu:
- Menggunakan HTML dan CSS
- Memiliki gambar, paragraf, heading
- Memiliki button dan alert
- Memiliki desain yang menarik
